# Configurações de referência

Os modelos comerciais identificam configurações de exemplo, não hardware detectado. Os perfis de potência e refrigeração continuam aproximações educativas, sem calibração ou validação para esses modelos. RAM e SSD são configurações escolhidas para o cenário. A potência da GPU integrada é uma parcela didática separada; não deve ser somada ao TDP oficial como medição real.

Clock base, turbo máximo e clock simulado são conceitos distintos. O clock simulado usa a carga da CPU e respeita o turbo do perfil. Temperatura pode reduzi lo abaixo do clock base. O modelo não reproduz o algoritmo de boost dos fabricantes. GHz não é uma classificação de desempenho entre arquiteturas.
